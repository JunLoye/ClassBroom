## 它是谁

ClassBroom 是一个为「上课的人」设计的桌面小工具。

它不像传统课表软件那样占据整个屏幕，而是**贴着屏幕顶端的一条细长横条**——横向铺开今天的所有课程，右侧挂着实时天气和预警，底部一行小字可以放倒计时、值日生、老师名字，或者任何你想看的文字。

窗口**不入驻任务栏**，随时可以从托盘唤出或收起。你打开电脑，它就在那里；你专心做事时，它安静地待在角落。

## 用起来是这样

| 场景 | 它做什么 |
| :--- | :--- |
| **早上开机** | 随系统自启，横条自动出现在屏幕顶部居中位置 |
| **课上走神时** | 眯一眼就知道还剩几分钟下课、下一节是什么 |
| **想专心工作** | 点右上角关闭，窗口收进托盘，屏幕干净了 |
| **天要下雨** | 天气区亮出预警标识，点开看详细内容 |
| **换班级 / 换学期** | 在设置里改课表，或直接拖入别人分享的 JSON |

## 开始使用

1. 下载 `ClassBroom-Setup-v1.2.0.exe` 并安装。
2. 首次启动后点击横条右侧的 **⚙ 齿轮** 进入设置。
3. 在「天气」页填入和风天气凭据，在「课程」页排好你的课表。
4. 点「保存并应用」，横条自动变回原尺寸并立刻刷新。

> 想让它开机就出现，在设置里勾选「开机自启」即可。

## 界面说明

**主界面**高度仅 92px，左侧时间轴、右侧天气、底部信息栏，全部一眼可达。

**设置界面**分四个标签页：

| 标签 | 你能做什么 |
| :--- | :--- |
| 天气 | 配置 API Host、经纬度、JWT 凭据与刷新频率 |
| 课程 | 按周一至周日切换，增删课程、点选科目、拖动或步进时间 |
| 显示 | 选择主题、调整底部字号与颜色、编辑自定义信息栏 |
| 关于 | 查看版本信息 |

### 自定义占位符速查

| 占位符 | 显示内容 | 占位符 | 显示内容 |
| :--- | :--- | :--- | :--- |
| `{time}` | 当前时分秒 | `{course}` | 正在进行的课程 |
| `{date}` | 当前日期 | `{nextCourse}` | 下一节课程 |
| `{datetime}` | 完整日期时间 | `{temperature}` | 当前气温 |
| `{weekday}` | 星期几 | `{weather}` | 天气描述与风力 |
| `{location}` | 经纬度 | `{targetName}` | 倒计时名称 |
| `{real_location}` | 地区名称 | `{daysTo}` | 距目标日期天数 |
| `{custom1~3}` | 自定义文本 | `{daysTo:2027-06-07}` | 距指定日期天数 |
| `{appName}` | 应用名称 | `{version}` | 当前版本号 |

## 数据放在哪里

所有设置——课表、天气凭据、主题偏好——都保存在你的本机注册表：

```
HKEY_CURRENT_USER\Software\ClassBroom
```

不上传、不联网同步、不收集任何使用数据。要彻底清除配置，删除这个注册表项即可，等同于恢复出厂设置。

## 常见问题

<details>
<summary><b>为什么关闭按钮不退出程序？</b></summary>

关闭只是把窗口收进托盘，方便你随时唤回。要真正退出，请右键托盘图标选择「退出」。
</details>

<details>
<summary><b>横条位置偏了 / 被其他窗口挡住？</b></summary>

横条默认居中贴顶。Windows 11 的「贴靠布局」或其他置顶工具可能抢占位置，调整后点一次右上角刷新按钮即可重新居中。
</details>

<details>
<summary><b>天气一直显示不出来？</b></summary>

天气依赖和风天气的 JWT 凭据。请确认 API Host、KID、SUB、ISS 与私钥都已正确填写且未过期；凭据错误时天气区会保持上次的缓存值。
</details>

<details>
<summary><b>换了电脑，课表能带走吗？</b></summary>

可以。导出一份 JSON 配置，在新电脑上导入或直接拖进窗口，课表就回来了。
</details>

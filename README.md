## 这是什么

ClassBroom 是一个桌面课程表小工具。

它不占满屏幕，只在桌面顶端显示一条 92 像素高的横条：左边是今天的课程，右边是天气，底部一行小字可以自己定义。窗口不占用任务栏，关闭后会收进系统托盘。

## 使用场景

| 情况 | 会怎样 |
| :--- | :--- |
| 开机 | 可以设置开机自启，横条自动出现在屏幕顶部中间 |
| 上课时 | 看一眼就知道还剩几分钟下课、下一节是什么 |
| 想安静做事 | 点右上角关闭，窗口收进托盘 |
| 配置天气 | 搜索地区后自动填入经纬度，也可选择不同天气服务商 |
| 有天气预警 | 支持预警的服务商会在天气区显示警示标签 |
| 换班级 / 换学期 | 在设置里改课表，或拖入别人分享的 JSON 配置 |

## 开始使用

1. 下载并运行安装包。
2. 首次启动后点横条右侧的齿轮图标进入设置。
3. 在「天气」页选择服务商；可搜索地区自动填入经纬度，按需填写服务商凭据，再到「课程」页排好课表。
4. 点「保存并退出」，窗口会恢复原尺寸并刷新。

> 想让开机自动启动，在设置里勾选「开机自启」

## 轮换课表与批量导入

在「课程」页选择轮换周期和起始周一。双周课表显示为 A 周和 B 周；更长周期按第 1–8 周轮换。调课需要先在「课表设置」中开启调课模式：开启期间的课程调整只作用于生效日期（默认今天），恢复为常规课表即删除该日调课。

界面中的完整日期统一显示为 `yyyy.MM.dd`；配置文件仍以 `yyyy-MM-dd` 保存，便于导入导出和日期计算。

Excel 模板包含「星期、开始时间、结束时间、课程」列；「周次」可选，省略时按第 1 周处理。「备注」可选。星期可写「周一」到「周日」，时间使用 `08:00` 格式，周次范围为 1–8。导入前会校验全部行并列出受影响的星期；确认后只替换表格中出现的周次与星期。

在「主界面」页保存多个显示方案，再为具体日期分配方案。到达该日期后会自动应用方案主题、天气/课表显隐、时钟秒数和底部信息。
